## Should you rename?

The recommendation is to rename, conditionally, and put the decision on a clock. The leading candidate is handful. Baste and crewrail are the runners-up. Give the decision two weeks. If no finalist survives testing, keep the current name and stop reopening the question.

The product lets one developer direct a team of coding agents through tracked, reviewable, repeatable work. A good name should suggest human supervision, durable structure, or independence from any particular agent provider. Meaning matters more than brevity, within about 8 characters.

The current name conflicts with Secure Access Service Edge, a major networking-security category. Both use the same spelling and the same pronunciation: sassy. Networking vendors already use the phrase SASE agent. They are also adopting agentic terminology. Adding agent to a search increasingly leads toward the wrong industry.

The counterargument matters. Searches with coding context already find the project, and there is no namesake inside its niche. This is a strategic problem, not an emergency. Renaming pays off mainly if attracting new users is a goal.

## What makes the decision difficult?

The biggest danger is choosing a replacement that already names another agent tool. Many obvious metaphors are occupied. Verification eliminated sennit, an existing multi-agent coding tool, and canton, dominated by a blockchain with its own agent ecosystem.

There is also a growing migration cost. The current name appears 141,784 times in 10,762 files. That occurrence count has grown 2.4 times since July. The measurement excludes linked repositories and external configuration. Renaming is an epic, even with existing rewrite tooling.

This is the fourth naming round in eight months. The missing ingredient is a stopping rule, more than additional candidates. A quieter name alone does not justify this work.

Handful wins because it describes the operating point: as many agents as one person can supervise. It is plain English, memorable, and 7 letters long. Its Python package and Rust crate names were free when checked. Its risks are generic search results and suggesting limited scale.

Baste is the strongest short alternative at 5 letters. Temporary stitching before a permanent seam matches agent drafts before host-owned completion. It also fits the existing patch, stitch, and bead vocabulary. However, Python and JavaScript package names are taken, and many listeners will think of cooking.

Crewrail is the most literal alternative at 8 letters: a team working on guided rails. Registry checks were clear. Its weakness is sounding like an accessory to CrewAI.

These checks are provisional. A missing domain record does not guarantee availability. The report did not include trademark clearance or real user testing.

## The shortlist and next steps

The remaining ranked names are stichos, senju, runclasp, oarlock, specyard, simul, and crewrill, in that order. Stichos has clean handles but spelling and pronunciation problems. Senju suggests many hands, with religious and existing software associations. Runclasp has strong handle availability but echoes Google's clasp command. Oarlock suggests leverage. Specyard emphasizes specifications more than supervision. Simul has an excellent chess metaphor but occupied handles. Crewrill is available but obscure.

Only handful, baste, and crewrail clearly beat the current name. Test those finalists by using aliases, rewriting the tagline, and checking spoken recall with 3–5 developers. Test what language models associate with each name, and run a trademark search for the survivor.

Decide on day 14. If a finalist survives, switch the public identity in one release. Migrate internal names afterward with compatibility fallbacks. Preserve historical bead identifiers. Keep structured agentic software engineering as a lowercase tagline, while dropping the acronym from branding.

If none survives, keep the current name and record a specific condition for reopening the decision.
