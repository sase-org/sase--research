## Cross-cutting findings

1. TUI stall/GC is the worst user-visible defect and is already beaded (`sase-1nc`, `sase-1gf`, `sase-lx`): gen-2 main-thread pauses to 38s (apollo) / 73s (athena), p95 >1.2s both hosts, hundreds–thousands of >1s main-thread events, plus pump/loop watchdog 5–9s recoveries. Evidence corroborated by two routes (stall jsonl + watchdog lines + triage bead).
2. Publication + housekeeping scheduler is in a chronic error state on both hosts: publication 1k+ errors/slice on apollo, deferred-archive/reference-wire/hood-no-runs/not-acknowledged on athena; backfill/retention/prune/sidecar/cleanup timeouts (90–300s) with `[output absent]` (work killed, no diagnostic). The hourly axe digest then re-emits up to 100 errors/hour, which is itself inbox noise.
3. Schema/wire skew is a concrete, fixable subset: athena `prompt_prose` rejected by `ArtifactLinkRowWire` while Python canonical (`_artifact_link_event_canonical.py:112`, `_artifact_link_store_support.py:31`, `_artifact_link_projection.py:23`, `_artifact_link_outbox_drain.py:486`, `referenced_by_planning.py:28`) all accept `prompt_prose`; `sase_core_rs artifact-reference wire stale expected 2/3 got 3/4` + missing `resolve_input_type` in launch failures point the same direction (Python/Rust pin drift; `sase-core-revision.txt` here is `6f8f016e`).
4. Recovery/retry loops generate load without fixing: SDD clone recovery retries git ops with 0.1s-scale deadlines (`sdd.health.conflicts timed out after 0.1s`) against corrupt/locked checkouts (detached HEAD, index.lock contention, empty object file) and logs a digest every cycle; `gate_turn_reclaim` 5s lock wait collides; `stale_running_cleanup` times out with `released=0 ... no_dead_running_process_claims` (i.e. it timed out doing nothing).
5. State hygiene backlog: 59 rescue dirs (47M, Nov only, apollo), 100-error/hour digests retained as mapped files, `unattributed` 166–581 GiB outside every `sase disk` owner with `managed_tmp` 0–5% free on apollo, 115/107 unread inbox rows, 29+6 never-self-resolving waits requiring manual kill/relaunch, `sync_conflict` commit retries.
6. Small deterministic bugs with clear fixes: `AgentWorkspaceRetention ... is not JSON serializable` (durable proc submit), codex `oversize → legacy fallback` on both hosts, `#research_swarm wait-word` splatter, `research.0` reserved-namespace collision, forced-reuse `left ... reserved after rebuild`, `BeforeSpawnCallback` import breakage. The `gate-input-footer NoMatches` crash trace is already mitigated in the current checkout (`gate_input_panel.py:168-176` early-return) — verify by observing one more TUI cycle rather than re-fixing.

## Ranked fixes / improvements (most valuable first)

1. **Bound or move TUI full-GC work off the main thread (sase-1nc class).** 38–73s main-thread pauses + p95 >1.2s + thousands of >1s events across both hosts is a freeze defect, not telemetry. Gate gen-2/idle collections by duty cycle, cap single-pause time, or collect off-thread; keep the existing stall jsonl as the acceptance metric (max/p95/main->1s counts).
2. **Make `sase disk` account for the `unattributed` majority and make `managed_tmp` pressure actionable.** 167–192 GiB unattributed on apollo with 0.0–4.9% free and KiB-scale reaps vs a 9.6 GiB target means the pressure notice cannot self-heal. Add the missing owner(s) (likely workspaces/checkouts/rescue) or narrow the definition, and ensure the reaper can actually free GiB or say what the human must delete.
3. **De-flap `agent_publication`: missing-target, withheld-archive, and unresolved-archive paths should not be hourly errors.** `gh_bbugyi200__nut: no usable agents publication target` with queued items errors every cycle (`publication_job.py:181-192`); athena `could not restore deferred prompt archive ... missing local source does not prove there was no prompt obligation` and `hood '1du' has no publishable runs` repeat identically. Downgrade known-parked/deferred/no-target states to warnings with backoff, keep errors for genuinely stuck drains, and extend the 120s drain / 1s cleanup budgets or split per-project deadlines.
4. **Fix `artifact_link_backfill` / `artifact_retention` / `sidecar_auto_sync` timeouts under real data sizes.** `touch index re-reduced 952 streams`, `reconcile_repair 96s`, `drain ... 121s` then `timed out after 300s`; `sidecar_auto_sync timed out after 120s` with `[output absent]`. Chunk per project, add heartbeats/progress so partial work is not discarded, schedule heavy backfills off-peak, and include the last completed phase in the timeout diagnostic.
5. **Repair or quarantine corrupt SDD clones instead of retrying them hourly.** Empty object (`88/fd06...`), `not a valid Git worktree / detached HEAD / index.lock`, `deadline expired before git operation` (0.1s health check) fail identically for days. `fsck`/re-clone the corrupt `bob-cli .../repos/plans` clone, raise the health-check deadline under load, and back off after N identical failures.
6. **Align the artifact-link wire schema (`prompt_prose`) and the `sase-core` pin.** Python accepts `prompt_prose` in four places but the wire validator rejects it, breaking athena publication for `plan:202611/research_commit_gap.md` on every run; `sase_core_rs artifact-reference wire stale` + missing `resolve_input_type` are the same drift class. Add the variant to the Rust wire, bump `sase-core-revision.txt` past the sase-core commit, and add a cross-repo wire test.
7. **Auto-clear never-self-resolving waits.** 35 sampled `Wait dependency can never self-resolve` rows (failed/killed blockers) require manual `kill + relaunch or clear`. Expire waits whose blocker is terminally failed/killed (or convert to one-click `Stranded bead` jumps everywhere), so the inbox does not accumulate dead waiters.
8. **Give `workspace-rescue` a retention/expiry story and fix the eviction root cause.** 59 Nov dirs / 47M on apollo is correct healing with no cleanup. Age out untouched rescues (e.g. 14d, matching artifact trash), surface one `restore-or-delete` action per rescue, and reduce `launch-time eviction of linked/external clones` + `lease-checkout forced reset` frequency.
9. **Fix durable-proc JSON serialization of `AgentWorkspaceRetention`.** `TypeError ... is not JSON serializable` broke `agent.cleanup` submits in a Nov-4 cluster (11k apollo log hits). Custom-encode or exclude the dataclass instead of passing it raw.
10. **Fix codex instruction `oversize → legacy fallback`.** Same notice both hosts; codex agents silently run degraded. Trim/shrink the bundle for codex or raise/split the limit, and include size + dropped section in the notice.
11. **Roll up axe/inbox noise.** Cap `ViewErrorReport` at one digest per root cause per day (not 100/hour), auto-dismiss routine `user-agent JumpToAgent` completions out of the priority inbox, and dedup `remote-attention` apollo→athena mirrors so triage beads (`sase-1nc`, `sase-1tm`, `bob-cli-*`) stay visible.
12. **Harden launch paths already visible in `launch_failures.*`.** Pin/CI-guard `BeforeSpawnCallback`-style imports (broke `tailnet-1a` land), `sase_core_rs` wire/binding skew, `research.0` reserved-namespace collision, `forced reuse ... left ... reserved` cleanup, and `#research_swarm wait` argument splatter (quote/validate multi-word prompt args). Each is small; together they are the launch-error background rate.
